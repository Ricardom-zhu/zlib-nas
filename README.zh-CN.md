# zlib-nas

[English](README.md) · **中文**

一个跑在 NAS 上的、给自己用的 **Z-Library 账号网页客户端**。

由 Ricardo 与他的大肥鱼阿静一同开发。

它不是镜像站，也不托管任何内容：它只是用**你自己的账号**去调 Z-Library 的 EAPI，
把收藏夹同步进本地 SQLite，再用一条"额度守卫"队列把书稳稳地下载到你指定的文件夹。

```
┌─────────────┐   HTTPS    ┌──────────────┐   局域网   ┌────────────────┐
│   浏览器     │ ─────────► │  zlib-nas    │ ────────► │   你的书库目录   │
│  （局域网）   │            │  FastAPI     │   文件     │    NAS / 硬盘   │
└─────────────┘            └──────┬───────┘           └────────────────┘
                                  │ EAPI（HTTPS）
                                  ▼
                            Z-Library 镜像站
```

## 为什么做这个

现有的客户端要么是浏览器插件，要么是桌面软件，要么是 Telegram 机器人。书放在 NAS 上的
人用不上这些：想要的是书架在 NAS 上、下载在 NAS 上、文件直接落到阅读器已经扫描的那个
目录里。

zlib-nas 只做这一件事：

- **收藏夹优先。** 整个收藏夹同步进 SQLite，翻书架**不烧额度**；只有真正取文件时才消耗。
- **额度守卫。** 每个任务开始前先读剩余额度，用完了就整条队列暂停，而不是一条条地报错。
- **流式落盘。** 200 MB 的 PDF 分块写磁盘，绝不整本读进内存。
- **密码不落地。** Z-Library 密码只在登录时用一次换回会话，磁盘上只留会话 Cookie（`0600` 权限）。
- **本地访问密码。** 首次打开先设一个密码（scrypt 加盐哈希，用户名可在设置页改），之后每次进页面要登录，会话有效一年。
- **前端零构建。** 纯 HTML/CSS/JS，没有 npm、没有 CDN、没有打包步骤。

## 功能

| | |
|---|---|
| 收藏夹 | 一键同步、本地筛选、一键加入或移出收藏、封面经服务端代理（NAS 连不上图床也能看） |
| 详情 | 每本书一个弹层：封面、完整元数据、清洗掉危险标记的简介、收藏开关、可收起的「相关推荐」（镜像站给出的相似书目）与「搜索作者」（按作者名关键词查其作品）两列书架 |
| 搜索 | 书名 / 作者 / ISBN，语言与格式筛选，翻页 |
| 下载 | 服务端队列、实时进度、失败重试、一键继续 |
| 历史 | 账号侧的下载历史，分页浏览，封面由服务端解析 |
| 本地库 | 列出磁盘上真实存在的文件，可直接下载 |
| 设置 | 镜像域名、密码登录**或**粘贴 Cookie 登录、修改本地用户名与密码、退出 |
| 运维 | `/api/health` 存活探针、`/api/status` 面板数据、本地访问密码、双语界面 |

## 快速开始

```bash
git clone https://github.com/<你的名字>/zlib-nas.git
cd zlib-nas
cp .env.example .env          # 可选：预先填好镜像域名
docker compose up -d --build
```

`.env` 和 `data/` 都在 `.gitignore` 里，你自己的凭证和书不会进版本库。

打开 `http://<NAS的IP>:8101` → 先设一个**访问密码**（本地账号，至少 8 位）→
**设置** → 填一个**在你的网络下能打开的站点**域名（如 `your-mirror.example`，不要带 `https://`）
→ 登录 → 点 **同步收藏**。本项目不内置、也不推荐任何镜像站。

访问密码只保护本页面，和 Z-Library 账号无关；忘了密码就执行
`docker compose exec web python -c "from app.store import Store; s = Store(); s.set_setting('local_password',''); s.set_setting('local_sessions','{}')"`
，下次打开会重新引导设密码。

不用 Docker：

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
DATA_DIR=./data uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 安全须知

这是**局域网工具**，下面几条请务必读完：

- **有本地访问密码，但没有 TLS。** 首次打开会引导设一个访问密码（scrypt 加盐哈希，用户名
  可在设置页改），之后没有正确密码就进不到页面，所以它不再是一个 "谁能连上端口谁就能用"
  的服务。但传输本身是明文 HTTP：口令和 Cookie 在局域网里以明文经过，同一网段能抓包的人
  还是能截到。因此**仍然不要直接暴露到公网**。需要远程访问请走 VPN，或在前面加一层带
  HTTPS 的反向代理。
- `data/session.json` 里是能直接登录你账号的 Cookie，文件权限已设为 `0600`，数据目录也要
  保护好。
- 退出登录会删掉会话文件，**同时**清掉镜像下来的收藏夹、相关缓存和缓存封面图，账号
  相关的东西不会在退出后留下。下载记录保留，因为它记的是这台机器拿过什么。
- 密码不会被保存。不想发送密码的话，用 Cookie 登录：登录状态的浏览器里复制
  `remix_userid` 和 `remix_userkey` 两项即可。
- 下载下来的书请仅作个人使用，并遵守你所在地的法律。
